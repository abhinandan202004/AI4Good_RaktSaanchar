# RaktaSanchaar Platform Guide

## For Patients
- Create blood requests
- Track request status
- View donor matches
- Chat with donors

## For Donors
- Register as donor
- Update availability
- Accept or reject requests
- View donation history

## For Coordinators
- Monitor requests
- Assign donors
- Manage emergencies

## For Blood Banks
- Manage inventory
- Verify donations
- Monitor shortages

## Chatbot Support
The chatbot can answer:
- Blood donation questions
- Thalassemia guidance
- Blood compatibility queries
- Platform-related questions
