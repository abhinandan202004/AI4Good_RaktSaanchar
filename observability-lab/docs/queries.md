# 🔍 Observability Lab — Query Cheat Sheet & Reference

This guide provides practical PromQL, LogQL, and TraceQL queries for monitoring, debugging, and correlating telemetry data across Prometheus, Loki, Jaeger, and Grafana.

---

## 1. 📈 Prometheus (PromQL)

### Request Rate (Throughput in Requests per Second)
* **Overall Service Throughput:**
  ```promql
  sum(rate(http_request_duration_seconds_count{app="fastapi"}[1m]))
  ```
* **Throughput by Endpoint Path:**
  ```promql
  sum(rate(http_request_duration_seconds_count{app="fastapi"}[1m])) by (handler)
  ```
* **Throughput by HTTP Status Code:**
  ```promql
  sum(rate(http_request_duration_seconds_count{app="fastapi"}[1m])) by (status)
  ```

---

### Error Rates & Availability
* **5xx Server Error Percentage (% of all requests):**
  ```promql
  (sum(rate(http_request_duration_seconds_count{app="fastapi", status=~"5.."}[1m])) / sum(rate(http_request_duration_seconds_count{app="fastapi"}[1m]))) * 100
  ```
* **4xx Client Error Rate (req/sec):**
  ```promql
  sum(rate(http_request_duration_seconds_count{app="fastapi", status=~"4.."}[1m]))
  ```

---

### Latency Percentiles (SLO & Performance Monitoring)
* **Median Response Time (p50):**
  ```promql
  histogram_quantile(0.50, sum(rate(http_request_duration_seconds_bucket{app="fastapi"}[1m])) by (le))
  ```
* **95th Percentile Response Time (p95):**
  ```promql
  histogram_quantile(0.95, sum(rate(http_request_duration_seconds_bucket{app="fastapi"}[1m])) by (le))
  ```
* **99th Percentile (Tail Latency - p99):**
  ```promql
  histogram_quantile(0.99, sum(rate(http_request_duration_seconds_bucket{app="fastapi"}[1m])) by (le))
  ```
* **Slow Endpoint Breakdown (p95 Latency per Path):**
  ```promql
  histogram_quantile(0.95, sum(rate(http_request_duration_seconds_bucket{app="fastapi"}[1m])) by (le, handler))
  ```

---

### Concurrency & Saturation
* **Active In-Flight Requests (Concurrent Traffic):**
  ```promql
  sum(http_requests_inprogress{app="fastapi"})
  ```
* **Total Cumulative Request Count:**
  ```promql
  sum(http_requests_total{app="fastapi"})
  ```

## 2. 📜 Loki (LogQL)

### Stream Filtering
* **All FastAPI Service Logs:**
  ```logql
  {app=~".*fastapi.*"}
  ```
* **Filter by Severity Level:**
  ```logql
  {app=~".*fastapi.*"} | json | level="ERROR"
  ```
* **Filter Warnings & Errors:**
  ```logql
  {app=~".*fastapi.*"} | json | level=~"ERROR|WARNING"
  ```

---

### JSON Field Extraction & Filtering
* **Find Slow Requests (> 500ms duration):**
  ```logql
  {app=~".*fastapi.*"} | json | duration_ms > 500
  ```
* **Filter by Specific HTTP Route & Status:**
  ```logql
  {app=~".*fastapi.*"} | json | http_path="/error" and http_status=500
  ```
* **Search by Trace ID (Log-to-Trace Correlation):**
  ```logql
  {app=~".*fastapi.*"} | json | trace_id="<YOUR_TRACE_ID_HEX>"
  ```
* **Search for Exception Stack Traces:**
  ```logql
  {app=~".*fastapi.*"} |= "exc_info" or "Unhandled exception"
  ```

---

### Log Metrics (Deriving Metrics from Log Streams)
* **Count Error Logs per Minute:**
  ```logql
  sum by (level) (count_over_time({app=~".*fastapi.*"} | json | level=~"ERROR|WARNING" [1m]))
  ```

## 3. 🔍 Jaeger & Trace Analysis

### Searching Traces in Jaeger UI (`http://localhost:16686`)
* **Service:** `fastapi-service`
* **Operation Filters:**
  - `GET /` : Baseline fast requests (< 5ms)
  - `GET /slow` : Heavy multi-span operation
  - `GET /error` : Error status spans with exception metadata
* **Tags Filter:**
  - `error=true` : Locate all failed transactions
  - `http.status_code=500` : Isolate server crashes
  - `db.system=postgresql` : Filter database sub-spans
* **Min Duration Filter:**
  - `1s` or `1200ms` : Easily filter out normal requests to isolate slow endpoints

## 4. 🔗 Unified Telemetry Correlation in Grafana

1. **Metrics to Logs:** Notice a spike in 5xx error rate on the Grafana Dashboard $\rightarrow$ Click on the Loki Logs panel filtered to the same time window.
2. **Logs to Traces:** Expand any JSON log entry in Loki $\rightarrow$ Click the **View Trace in Jaeger** button generated by the `trace_id` derived field.
3. **Traces to Logs:** Open Jaeger in Grafana Explore $\rightarrow$ Click on a span $\rightarrow$ Select **Show logs for this span** to immediately retrieve contextual log lines from Loki matching that trace.
